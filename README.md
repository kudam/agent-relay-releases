# Agent Relay Downloads

Download the latest macOS app from [GitHub Releases](https://github.com/kudam/agent-relay-releases/releases/latest). The Sparkle update feed is hosted at https://kudam.github.io/agent-relay-releases/appcast.xml. The private source repository remains at https://github.com/kudam/hybrid-agent-harness.

Release archives are verified by Sparkle's Ed25519 signatures embedded in Agent Relay. This repository does not contain the application's source code.
